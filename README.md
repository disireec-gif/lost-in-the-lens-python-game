# Lost in the Lens

## About the Game

Lost in the Lens is a text-based Python adventure game where the player explores different locations, collects photography gear, manages inventory, and works toward completing the adventure.

## Python Skills Demonstrated

- Functions
- Loops and conditional statements
- Dictionaries and data structures
- User input and command handling
- Inventory management
- Game navigation and program logic

## How to Play- 

Explore the wilderness by entering commands to move between locations, collect photography gear, check your inventory, and complete the adventure.

### Commands


- go [direction]
- get [item]
- look
- inventory
- help
- quit
